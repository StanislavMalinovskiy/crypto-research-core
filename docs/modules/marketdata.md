# marketdata

- **Responsibility:** append-only raw observations and transaction payloads, recorded-swap normalization, immutable dataset snapshots, bounded point-in-time market observations, separated price/liquidity/USD-conversion facts and point-in-time token universes. Real provider adapters and stream-gap recovery remain future work.
- **Owned data:** `marketdata.raw_chain_events`, `marketdata.raw_transactions` (one provider payload per chain + transaction + provider with trusted-clock `received_at`/`admitted_at`/`ingested_at`), `marketdata.normalized_swaps`, `marketdata.dataset_snapshots`, `marketdata.dataset_snapshot_members`, `marketdata.price_observations` (swap-derived native price with quote asset; point-in-time index), `marketdata.liquidity_observations` (pool liquidity with raw reserves; point-in-time index), `marketdata.usd_conversion_facts` (immutable conversions referencing both source observations with method version) and `marketdata.universe_snapshots` + `marketdata.universe_members` (fingerprinted point-in-time universes with recorded inclusion/exclusion). Raw identity includes provider; normalized identity is `(chain_id, transaction_value, event_locator)` and retains provider, raw digest and transformation version as lineage. Secondary indexes exist only for the documented point-in-time queries; the new tables are unpartitioned by explicit decision until spike-measured volume exists.
- **Public API:** `MarketDataApi` synchronously replays a recorded dataset, finalizes an immutable snapshot and returns normalized observations bounded by window, cutoff and optional dataset fingerprint. It exposes immutable domain records, never JDBC, Jackson or provider types. The new fact tables are written and queried through module-internal use cases until the ingestion and evaluation changes expose their consumers.
- **Allowed dependencies:** `kernel::api`.
- **Transactions:** every raw observation commits through the existing raw-storage use case before a separate normalization transaction; parse failure therefore retains raw evidence. Dataset finalization is one short module-owned transaction after member selection.
- **Numeric/time contract:** quantities are exact integers; price is scale 18, liquidity scale 8 and confidence scale 4. Authoritative times are UTC `Instant` values normalized to microseconds before normalized-evidence comparison and persisted as `TIMESTAMPTZ(6)`.
- **Reproducibility:** snapshot content is sorted by normalized identity and hashed as algorithm-qualified SHA-256 using versioned UTF-8 length-prefixed fields. Content includes normalized values, raw digest lineage and transformation version; equal permutations reproduce the fingerprint and changed evidence or canonicalization does not.
- **Invariants:** raw and normalized evidence is immutable; equal replay is idempotent and conflicting evidence fails without overwrite; point-in-time queries have a total order and exclude observations after the declared cutoff; other modules never read market-data tables directly.
- **Non-goals:** live provider connectivity, gap recovery, provisional/finality handling, signal generation, wallet scoring, risk decisions, outcome valuation and EVM provider implementation.
- **Main tests:** pure validation and canonicalization behavior plus PostgreSQL 18.6 tests for V1/V2 schema ownership, raw-first parse failure, normalized retry/conflict, cutoff exclusion, total ordering, snapshot permutation and fingerprint sensitivity, and V5–V8 storage: raw transaction idempotency/conflict/batch (including a 10,000-row volume batch), price/liquidity observation idempotency and point-in-time windows, USD-conversion immutability and universe point-in-time membership.
