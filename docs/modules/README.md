# Module documentation

These pages define ownership and public boundaries for the six Spring Modulith modules. The exact dependency graph is controlled by [Architecture](../ARCHITECTURE.md) and accepted [ADRs](../adr/README.md); the [Roadmap](../ROADMAP.md) owns product sequencing. Exact API types and event schemas are introduced only by the OpenSpec change that implements them.
