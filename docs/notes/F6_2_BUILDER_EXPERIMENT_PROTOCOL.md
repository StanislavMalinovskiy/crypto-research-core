## One original attempt per candidate

First handoff, refusal/blocker, budget expiry or process termination ends the original attempt; freeze the complete available result immediately, including dirty/untracked files, test hashes, logs, commands and handoff. If state is lost or input/visibility equality cannot be proved, mark the run invalid; do not silently select the best of reruns. Owner-approved restarts use a documented common rule and retain invalid-attempt evidence. Product changes after any run invalidate comparability and require a newly frozen experiment, not individual repair rounds.
